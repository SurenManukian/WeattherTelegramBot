
# Weather Bot
 
## О проекте

Этот телеграм-бот определяет текущую погоду в выбранном городе. Бот использует Open-Meteo API для получения координат и прогноза, а также возвращает:

- температуру
- скорость ветра
- направление ветра
- влажность
- краткое описание погоды

Бот написан на Python с использованием библиотеки `aiogram`.

## Возможности

- `/start` — приветствие и краткая информация
- `/help` — подсказки по использованию
- `/get_weather` — запрос города и вывод прогноза

## Требования

- Python 3.9+ (рекомендуется)
- Установленные пакеты:
  - `aiogram`
  - `requests`
  - `python-dotenv`

## Установка

1. Склонируйте репозиторий:

```bash
git clone https://github.com/your-username/your-repo.git
cd BotWeather
```

2. Установите зависимости:

```bash
pip install aiogram requests python-dotenv
```

## Настройка

1. Создайте файл `.env` в корне проекта.
2. Внутри файла добавьте ваш токен бота:

```env
TOKEN=ваш_токен_телеграм_бота
```

> Токен можно получить у `@BotFather`.

## Запуск

```bash
python bot.py
```

После запуска бот начнет опрашивать Telegram и будет готов принимать команды.

## Как использовать

1. Напишите боту `/start`.
2. Затем отправьте `/get_weather`.
3. Введите название города, например:
   - `Москва`
   - `Санкт-Петербург`
   - `Владикавказ`

Бот ответит текущей температурой, влажностью, ветром и описанием погоды.

## Структура проекта

- `bot.py` — точка входа, конфигурация бота и запуск `Dispatcher`
- `handlers/handler_main.py` — основные обработчики команд и логика погоды
- `config.py` — дополнительные настройки (если используются)
- `.env` — скрытые переменные окружения

## Замечания

- Убедитесь, что у вас корректный токен
- Бот использует Open-Meteo, поэтому должен быть доступ в интернет
- Если город не найден, бот предложит ввести название повторно

## Развитие

Проект можно расширить, добавив:

- прогноз на несколько дней
- выбор языка интерфейса
- хранение истории запросов пользователя
- улучшенный вывод с кнопками и меню
